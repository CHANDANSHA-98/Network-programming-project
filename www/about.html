About this project

MiniHTTP is a lightweight HTTP/1.1 server and client built from scratch in C using the Winsock API on Windows, as a network-programming project.

What's implemented
🔌

TCP socket programming

Manual bind, listen, accept and connect calls over Winsock — no HTTP framework involved.

🧵

Multi-threaded

One CreateThread per connection, with critical sections guarding the shared log file and stats counters.

📨

HTTP request parsing

Reads method, path, query string, headers and body by hand, including chunked Content-Length reads for POST.

🗂️

Static file serving

Serves everything in www/ with correct Content-Type headers and basic path-traversal protection.

🔁

Keep-Alive

Multiple requests per TCP connection, matching real HTTP/1.1 client behaviour.

🔐

Basic Auth admin panel

The /admin route and its JSON APIs decode and verify the Authorization header before serving anything.

Status codes handled

200 OK   400 Bad Request   401 Unauthorized   403 Forbidden   404 Not Found — every response's real status code is written to access.log, which powers the visitor log in the admin dashboard.

Companion tools

client.c — a matching HTTP client that can talk to this server or any real website. client_loaadtest.c — a small load-testing client used to sanity-check the server under concurrent connections.
